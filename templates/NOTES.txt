ACCESSING THE AGENT:

  Since no Service is exposed, access the agent via kubectl exec:

  # Find agent pod on current node
  kubectl get pods -n {{ include "reel.namespace" . }} -l app.kubernetes.io/component=agent

  # Execute reel commands
  kubectl exec -n {{ include "reel.namespace" . }} <pod-name> -- reel get workloads
  kubectl exec -n {{ include "reel.namespace" . }} <pod-name> -- reel list checkpoints
